# ✨ Luxury Editorial Web UI

The Nullify Web Console is inspired by modern luxury editorial design (such as [useravn.com](https://www.useravn.com/)), rejecting generic corporate SaaS styles in favor of a timeless, high-contrast aesthetic.

---

## Design System Foundations

- **Color Palette**: High-contrast charcoal ink (`#191510`) set against warm heritage cream (`#f9f8f6`), accented with soft titanium borders and deep ambient blue shadows.
- **Typography**: **Mona Sans** with negative letter-spacing (`-0.038em`) paired with monospace accents for binary telemetry.
- **Visual Flourishes**: Ornate vintage engraving corner flourishes in all four hero corners, layered over a halftone Michelangelo-inspired robot artwork.

---

## Interactive Hero Headline
The hero features the animated brand headline:
> **"See it. Trace it. Nullify it."**
- **Dynamic Ink-Draw Underline**: A feathered SVG curve under *Nullify it.* draws smoothly from left to right on page load.
- **Autonomous Heartbeat Cycle**: An 8.5-second low-frequency pulse highlights each phase in sequence (`See` $\to$ `Trace` $\to$ `Nullify`), symbolizing the continuous detection cycle.

---

## Bento Grid Analysis Console

The results dashboard displays findings in an intuitive bento-box grid:
- **Radial Confidence Gauge**: Smooth animated SVG progress arc displaying 0%–100% confidence.
- **6-Agent Execution Visualizer**: Step-by-step progress tracking for each agent.
- **Executive Rationale Card**: Plain-English threat analysis written by the Reasoning Agent.
- **MITRE ATT&CK Matrix Badges**: Clickable tactical threat tags.
- **Synthesized YARA Rule Card**: Dark-mode syntax-highlighted rule with a 1-click clipboard copy button.
